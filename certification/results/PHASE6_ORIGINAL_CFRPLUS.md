- Compiler: gcc 13.3.0, `-O2 -Wall -fcommon`, non-MPI single-process target
  (the Makefile's commented-out non-MPI link line), plus
  `compressor/libcompressor.a` built with g++ 13.3.0.

### Latent bug found in original source (documented, NOT silently fixed)

`cfr.c:1546-1547` (chance-node RIVER_CUTOFFS path): `memset(childVals, 0,
sizeof(childVals[0]) * numHands)` where `childVals` is a VLA of length
`params->numHands[tree->round]` < `numHands`. Writes up to
8×(numHands−childNumHands) zero bytes past the VLA. Ubuntu 24.04's default
`_FORTIFY_SOURCE=3` aborts on this for Leduc (`*** buffer overflow
detected ***`); Kuhn (single round) never reaches the path. The over-written
entries are never read (consumer loop `cfr.c:1573-1583` is bounded by
`childNumHands`).

**Impact proof:** a one-line patched copy
(`certification/scripts/CFR_plus_patched/`, memset length → `childNumHands`)
produces **byte-identical `trunk` checkpoints (SHA-256 equal) at iterations
1, 2, 5, 10, 100, 1000 on leduc.game**. The original math is unaffected on
this platform. The immutable `third_party/CFR_plus` source was not modified.

## 6.2 Original RNG oracle — result: **BIT_EXACT (16/16)**

Oracle: `certification/oracles/rng/mt_seed{0,1,42,6874}_n{10,100,1000,10000}.{bin,txt}`
generated by `certification/scripts/rng_oracle.c` linked against the original
`rng.c` (untouched). SHA-256 of every `.bin` in `certification/oracles/SHA256SUMS`.

Comparison implementation: `certification/scripts/mt19937_independent.py` —
an independent pure-Python MT19937 written from the published algorithm.
Result: `RNG_ours[i] == RNG_original[i]` **bit-for-bit for all 16
seed×count combinations** (byte_equal=True on raw little-endian uint32
streams).

## 6.3 Kuhn original CFR+ oracle — GENERATED + determinism PASS

`./cfr_nofortify game=kuhn.game iters=N target=0 dump=...` for
N ∈ {1, 2, 5, 10, 100, 1000} → `certification/oracles/cfrplus_runs/kuhn_iN/`.
Checkpoints contain raw int32 regrets + int32 accumulated strategy
(192 bytes for Kuhn = 2 players × 12 infoset-actions × (regret+avg) × 4 B).

- Determinism: independent re-run at N=1000 → **SHA-256 identical**
  (`6b60a5b3d3700bf0c3da7256116d6961e6f4fe4b3ed442ee0cb6b372f665ea3f`).
- Exploitability of average strategy at iter 1000: **0.107350982 mSBet/h**;
  BR values (−0.055488303, +0.055703005) bracket the known Kuhn game value
  −1/18 = −0.0555556 sb/hand. ✓
- `KUHN CFR+ AUTHOR-SOURCE BIT EXACT (ours vs original)`: **NOT_TESTABLE** —
  no project implementation exists in this repository to compare against.
  The author-source side of the oracle is fully generated and frozen.
