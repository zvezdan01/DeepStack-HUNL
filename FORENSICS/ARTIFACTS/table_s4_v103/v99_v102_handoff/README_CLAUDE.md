## Important evidence boundary

These are forensic structural witnesses, not recovered historical DeepStack source code.
Do not promote V86/V43 continuation semantics to primary-source facts.

V99 showed `N = 3D - 3`, so node/decision/edge Size interpretations are algebraically non-identifying
on this family. V100 also found that the primary source calls the column only `Size`, not explicitly
the paper's formal `decision points` metric.

V102's exact nominal-center identity is therefore a structural fingerprint, not proof of the private
operational counter.
