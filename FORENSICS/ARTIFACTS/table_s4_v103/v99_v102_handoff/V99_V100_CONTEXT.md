# V99/V100 context

## V99 identifiability collapse

For all seven reconstructed trees:

`N_public = 3*D_decision - 3`
`E_edges = N_public - 1 = 3*D_decision - 4`.

Therefore an affine Size model in any of these dependent counts can be reparameterized into another.
The seven published rows cannot by themselves identify the historical storage/counting object.

## V100 source terminology boundary

The DeepStack main paper explicitly uses the term `decision points` when it means the combination of
public state and private hand. Table S4 instead labels the column only `Size` and describes it as the
size / computational requirements of the solved lookahead tree.

Therefore `Size = decision points` is not a primary-source fact.
